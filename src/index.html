Set up voice chat

Discord and games only listen to a microphone. Echo Board sends your voice and your sounds into a virtual microphone, and you pick that microphone in Discord.

Echo Board can install one for you: VB-CABLE, a free virtual audio cable by VB-Audio.

  1. Click Install virtual cable.
  2. Windows asks to allow changes: click Yes.
  3. Windows asks to install the VB-Audio driver: click Install.
  4. Restart your PC when it's done.
  1. Click Install virtual cable.
  2. Enter your Mac password when asked.
  3. Done. No restart needed.

Then in Discord

User Settings › Voice & Video › Input Device: choose CABLE Output. Turn off Krisp / noise suppression. In games, pick the same device as your microphone.

VB-CABLE is made by VB-Audio (vb-cable.com). VB-CABLE is a donationware, all participations are welcome. You can donate on their site.

Already use BlackHole or VoiceMeeter? Pick it under Settings › Send to instead.

Getting sounds into voice chat

Discord and games only listen to a microphone. Echo Board mixes your real mic with your sounds and sends both into a virtual cable, a free driver that acts like a fake mic.

1. Install a virtual cable (one time)

Easiest: click No virtual cable at the top (or Settings › Install…) and Echo Board installs VB-CABLE for you. Or install one yourself:

  • Windows: VB-Audio Virtual Cable. Install it, then restart your PC. vb-audio.com/Cable
  • Mac: VB-CABLE (same site) or BlackHole 2ch. existential.audio/blackhole

2. Point Echo Board at it

In Settings, set Send to to CABLE Input (Windows) or BlackHole 2ch (Mac), and pick your real mic under Your microphone.

3. Point Discord / the game at the cable

Set the voice Input Device to CABLE Output (Windows) or BlackHole 2ch (Mac). Keep Echo Board open while you play.

Tip: in Discord, turn off Krisp / noise suppression and set input sensitivity low (or use push-to-talk). Noise suppression treats music and sound effects as noise and can mute them.

Text to speech

Type in the box under the pads and press Enter (Shift+Enter for a new line). The voice plays into voice chat just like a pad. Free AI voices are the default: natural-sounding voices that run on your computer at no cost (built in, works offline). Save to pad keeps the line as a sound on the selected pad, and recent lines appear as chips you can click to replay.

Launchpad

Newer Launchpads (X, Mini MK3, Pro MK3) are switched into Programmer mode automatically, so the 8×8 grid lines up and the pads light up in your colors. Any other MIDI controller works too: select a pad, press Learn button, then hit the button you want.

Panic button: Esc stops everything, and Ctrl+Shift+K (Cmd+Shift+K on Mac) works even while a game is focused.
